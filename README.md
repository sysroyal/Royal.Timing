## 📖 درباره پروژه

**برنامه‌ریزی و مدیریت نوبت‌ها** یک نرم‌افزار برای ایجاد، مدیریت و مشاهده برنامه‌های نوبتی بین چند نفر است.

این پروژه با هدف ساده کردن فرآیندی ساخته شده که معمولاً با استفاده از فایل‌های Excel، جدول‌های دستی یا حتی کاغذ انجام می‌شود.

کاربر می‌تواند افراد موردنظر خود را تعریف کند و برای آن‌ها برنامه نوبتی ایجاد کند؛ سپس برنامه را بر اساس روز، هفته، ماه یا سال مشاهده و مدیریت کند.

---

## 💡 داستان شکل‌گیری پروژه

این پروژه از یک نیاز کاملاً واقعی و خانوادگی شروع شد.

برای نوبت‌بندی بین فرزندان مادربزرگم، لازم بود مشخص شود که هر روز یا هر نوبت، مسئولیت **تهیه غذای مادربزرگ** بر عهده کدام یک از فرزندان است.

در ابتدا برای انجام این کار از **Excel** استفاده می‌کردم.

برای هر ماه یک جدول ایجاد می‌کردم، روزهای ماه را وارد می‌کردم و سپس افراد را بین روزهای مختلف تقسیم می‌کردم.

در ابتدا این روش ساده به نظر می‌رسید؛ اما با گذشت زمان مشکلات آن بیشتر مشخص شد.

هر ماه باید جدول جدیدی ایجاد می‌شد.

تعداد روزهای ماه‌ها متفاوت بود.

روز شروع ماه‌ها با یکدیگر فرق داشت.

گاهی لازم بود نوبت یک نفر جابه‌جا شود.

گاهی فردی به برنامه اضافه یا از آن حذف می‌شد.

و برای پیدا کردن پاسخ سؤالات ساده‌ای مانند:

> «نوبت چه کسی در یک تاریخ مشخص است؟»

یا:

> «نوبت بعدی من چه زمانی است؟»

باید دوباره جدول‌ها بررسی و محاسبه می‌شدند.

---

## 🤔 ایده اصلی

در نهایت یک سؤال ساده به ذهنم رسید:

> **چرا باید هر ماه این برنامه را از اول در Excel ایجاد کنم؟**

اگر کامپیوتر می‌تواند تقویم را ایجاد کند، تعداد روزهای ماه را تشخیص دهد، روز هفته را محاسبه کند و نوبت‌ها را بین افراد تقسیم کند، چرا این کارها را دستی انجام دهیم؟

همین سؤال، نقطه شروع این پروژه شد.

چیزی که ابتدا فقط برای **نوبت‌بندی تهیه غذای مادربزرگم** ایجاد شده بود، به تدریج به یک ایده عمومی برای مدیریت نوبت‌ها تبدیل شد.

# 🎯 هدف پروژه

هدف اصلی پروژه این است که برنامه‌ریزی نوبت‌ها را از یک فرآیند دستی و زمان‌بر، به یک سیستم ساده و قابل مدیریت تبدیل کند.

این پروژه می‌تواند برای موقعیت‌های مختلف مورد استفاده قرار گیرد؛ از یک خانواده کوچک گرفته تا گروه‌ها، تیم‌ها و حتی محیط‌های کاری.

## 👥 مدیریت افراد

امکان اضافه کردن افراد مختلف به یک برنامه.

برای مثال:

```text
علی
رضا
محمد
حسن
مهدی
```

پس از تعریف افراد، نوبت‌ها می‌توانند بر اساس ترتیب مشخص بین آن‌ها تقسیم شوند.

---

## 🔄 نوبت‌دهی چرخشی

برنامه می‌تواند نوبت‌ها را به شکل چرخشی بین افراد تقسیم کند.

برای مثال:

| روز      | مسئول |
| -------- | ----- |
| شنبه     | علی   |
| یکشنبه   | رضا   |
| دوشنبه   | محمد  |
| سه‌شنبه  | حسن   |
| چهارشنبه | مهدی  |
| پنجشنبه  | علی   |
| جمعه     | رضا   |

با ادامه برنامه، ترتیب نوبت‌ها بین افراد گردش خواهد کرد.

## ⚖️ تقسیم عادلانه نوبت‌ها

یکی از اهداف اصلی پروژه، ایجاد امکان تقسیم متعادل مسئولیت‌ها بین افراد است.

به کمک سیستم نوبت‌دهی می‌توان تعداد نوبت‌های هر شخص را بررسی کرد و از ایجاد اختلاف یا تقسیم نامتوازن مسئولیت‌ها جلوگیری کرد.

---

## 🗓️ برنامه‌ریزی ماهانه

به‌جای ایجاد یک فایل Excel جداگانه برای هر ماه، تقویم ماهانه به‌صورت خودکار ایجاد می‌شود.

برنامه می‌تواند روزهای ماه و نوبت افراد را در کنار یکدیگر نمایش دهد.

## 📆 برنامه‌ریزی سالانه

# 🧠 فلسفه پروژه

ایده اصلی پروژه بسیار ساده است:

> **کاربر نباید کاری را که کامپیوتر می‌تواند به‌صورت خودکار انجام دهد، چندین بار تکرار کند.**

اگر نرم‌افزار می‌تواند:

* تقویم را ایجاد کند،
* تعداد روزهای ماه را تشخیص دهد،
* روز هفته را محاسبه کند،
* نوبت‌ها را ایجاد کند،
* نوبت افراد را مدیریت کند،
* و تعداد نوبت‌های هر شخص را محاسبه کند،

پس نیازی نیست کاربر تمام این کارها را به‌صورت دستی انجام دهد.

# 📊 چرا Excel کافی نبود؟

Excel یک ابزار بسیار قدرتمند است، اما زمانی که یک فرآیند مرتباً تکرار می‌شود، استفاده از جدول‌های دستی می‌تواند زمان‌بر و مستعد خطا باشد.

| روش سنتی                  | این پروژه              |
| ------------------------- | ---------------------- |
| ایجاد جدول برای هر ماه    | مدیریت متمرکز برنامه   |
| ورود دستی تاریخ‌ها        | مدیریت خودکار تاریخ    |
| محاسبه دستی نوبت‌ها       | نوبت‌دهی خودکار        |
| تغییرات دشوار             | مدیریت ساده‌تر تغییرات |
| جستجوی دستی               | دسترسی سریع به نوبت‌ها |
| وابستگی به فایل‌های مختلف | یک سیستم یکپارچه       |

هدف این پروژه حذف Excel نیست؛ بلکه **خودکار کردن فرآیندهایی است که به‌صورت مداوم در Excel تکرار می‌شوند.**
